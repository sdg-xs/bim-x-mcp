# BIM X MCP

BIM workflow resources for dimension-led modeling in Autodesk Revit through the BIMweight/Revit MCP.

## BIMCMP skill

The reusable skill is in [`skills/bimcmp`](skills/bimcmp). It plans work by evidence, dependency, and BIM category; uses Revit MCP for model operations; and reserves computer use for Revit approval dialogs that the user has authorized.

Use `$bimcmp` with the drawing set and requested categories. The skill's planning guide is at [`skills/bimcmp/references/model-planning.md`](skills/bimcmp/references/model-planning.md).
